Aero Privacy Policy

Last updated: 2026

Aero is a local-first browser extension designed to help users search and manage their browsing data efficiently.

1. Data Collection

Aero does NOT collect, store, transmit, or sell any personal data to external servers.

2. Local Storage

Aero stores the following data locally in the user's browser only:

  • Saved pages
  • Page snippets
  • User settings
  • Search preferences

3. Permissions Usage

Aero may request the following permissions:

  • History: Used only to enable searching previously visited pages (when enabled by user)
  • Bookmarks: Used only to include bookmarks in search results
  • Tabs / Active Tab: Used to save the current page
  • Storage: Used to store Aero data locally

4. Data Sharing

Aero does not share any data with third parties.

5. Internet & Servers

Aero operates fully offline/local-first and does not require a backend server.

6. User Control

Users can delete all stored data at any time from the extension settings.

7. Contact

If you have questions, contact: your-email@example.com
